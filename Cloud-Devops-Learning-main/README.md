# Cloud & DevOps Learning Dashboard

A responsive learning dashboard created using HTML, CSS and JavaScript.

## Features

- AWS, Linux, Git and Networking learning topics
- Mark topics as completed
- Automatic progress calculation
- Animated learning progress bar
- Dark mode
- Data saved using Local Storage
- Mobile responsive design

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage
